How to Host This Dashboard For Free

1 GitHub Pages (Recommended & Easiest)

  1. Create a free account on GitHub.com.
  2. Create a new repository named my-dashboard.
  3. Upload this single file and name it strictly index.html.
  4. Go to Settings > Pages in your repository menu.
  5. Select the main branch as the source and click Save.
  6. Your site will be hosted online for free within 1-2 minutes!

2 Netlify Drop (Drag & Drop - No Code Required)

  1. Save this web page as index.html on your computer.
  2. Go to app.netlify.com/drop.
  3. Drag and drop the folder containing your index.html file into the browser box.
  4. Netlify instantly deploys your site with an SSL certificate and live HTTPS URL.

3 Vercel

Sign up at Vercel.com, import your GitHub repository, and click Deploy. It offers extremely fast edge performance for free.
